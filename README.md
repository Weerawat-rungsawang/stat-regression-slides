# ปัจจัยที่มีผลต่อคะแนนสอบปลายภาค (G3) — สไลด์นำเสนอ

สไลด์ HTML ไฟล์เดียว (14 หน้า) สรุปผลการวิเคราะห์ **การถดถอยพหุคูณ** จากรายงาน PDF 9 หน้า
ชุดข้อมูลนักเรียนโปรตุเกส 2 โรงเรียน (Cortez & Silva, 2008) · n = 649

## เปิดใช้
- ดับเบิลคลิก `index.html` แล้วกด `F` เพื่อเต็มจอ
- `←` `→` / Space เลื่อนสไลด์ · `Home` `End` ไปหน้าแรก/สุดท้าย · คลิกซ้าย-ขวาของจอ หรือปัดบนจอสัมผัส
- `Ctrl+P` ปริ้นเป็น PDF 14 หน้า (หน้าละ 1280×720) สำหรับแจกอาจารย์
- ไฟล์นี้ทำงานออฟไลน์ 100% (ฝังฟอนต์ไทยและรูปกราฟไว้ในไฟล์ ไม่มีการเรียกออกอินเทอร์เน็ต)

## หมายเหตุเรื่องตัวเลข
ตัวเลขทุกตัวบนสไลด์คัดลอกจากตารางผลลัพธ์ในรายงานต้นฉบับ ไม่ได้รัน R ใหม่
ยกเว้น `n = 649` ซึ่งคำนวณย้อนกลับจาก F = (R²/k) ÷ ((1−R²)/(n−k−1)) ด้วย R² = 0.3105, k = 15, F = 19
